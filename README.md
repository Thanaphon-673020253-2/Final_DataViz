# Digital Threats & Internet Freedom Dashboard

**ภัยคุกคามในโลกดิจิทัลกับเสรีภาพอินเทอร์เน็ต: วิเคราะห์ข่าวปลอมและข้อมูลบิดเบือน อาชญากรรมออนไลน์ ความเสี่ยงจาก AI และสถานการณ์เสรีภาพอินเทอร์เน็ต เพื่อทำความเข้าใจภัยคุกคามที่เกี่ยวข้องกับสังคมไทย**

---

## 1. ภาพรวมโครงการ

Dashboard แบบหน้าเดียว (Single-page Dashboard) ที่พัฒนาด้วย **HTML, CSS, และ JavaScript (Chart.js)** โดยใช้ `index.html` เป็นไฟล์หลัก ศึกษาและนำเสนอภัยคุกคามในโลกดิจิทัลผ่าน 4 ชุดข้อมูลหลัก:

| ชุดข้อมูล | แหล่งที่มา | ช่วงเวลา | ขอบเขตการวิเคราะห์ |
|---|---|---|---|
| **AFNC** | ศูนย์ต่อต้านข่าวปลอมประเทศไทย | ม.ค. 2019 – ต.ค. 2026 | 17,726 รายการ (14,458 รายการมี Verdict) |
| **ACSC** | ศูนย์ปฏิบัติการแก้ไขปัญหาอาชญากรรมออนไลน์ | พ.ย. 2025 – ต.ค. 2026 | 48 รายงานสถิติรายสัปดาห์ |
| **AI Incident Database** | AI Incident Database (AIID) | 1983 – 2026 | 1,775 เหตุการณ์ความเสียหายจาก AI (ระดับโลก) |
| **Freedom on the Net** | Freedom House | ปีข้อมูล 2010 – 2024 | 940 เรคคอร์ด ครอบคลุม 72 ประเทศ |

### คำถามหลักของโครงการ (Research Question)
> *“ภัยคุกคามทางดิจิทัลรูปแบบใดบ้างที่ปรากฏในประเทศไทย และสภาพแวดล้อมด้านเสรีภาพอินเทอร์เน็ตมีความเกี่ยวข้องกับการเข้าถึงข้อมูลและสิทธิของประชาชนอย่างไร?”*

## 3. วิธีเปิดใช้งาน Dashboard

เนื่องจากโมเดิร์นเบราว์เซอร์มีนโยบายความปลอดภัย (CORS Policy) ป้องกันไม่ให้ JavaScript อ่านไฟล์ JSON ในเครื่องเมื่อเปิดด้วย `file://` จึงแนะนำให้เปิดผ่าน **Local Web Server** อย่างง่าย ดังนี้:

### วิธีที่ 1: รันผ่าน Python (แนะนำ - ไม่ต้องติดตั้งโปรแกรมเพิ่ม)

เปิด Terminal หรือ Command Prompt ในโฟลเดอร์โปรเจกต์:

```bash
cd Final_DataViz
python -m http.server 8080
```

จากนั้นเปิดเว็บเบราว์เซอร์ไปที่:
👉 **[http://localhost:8080](http://localhost:8080)**

### วิธีที่ 2: รันผ่าน Node.js (npx)

```bash
npx serve .
```

### วิธีที่ 3: เปิดผ่าน VS Code Live Server Extension
- คลิกขวาที่ไฟล์ `index.html` แล้วเลือก **"Open with Live Server"**

## 4. โครงสร้างและการจัดหมวดหมู่ใน Dashboard

Dashboard จัดแบ่งเป็น 7 หมวดหมู่หลักแบบ Single-page พร้อมแถบนำทาง (Sidebar Navigation):

1. **Header / Hero Section:**
   - หัวข้อหลักภาษาไทยและภาษาอังกฤษ
   - คำอธิบายโครงการและคำถามหลัก (Research Question)
2. **Section A: ภาพรวมภัยคุกคามดิจิทัล (Overview):**
   - 4 KPI Cards สรุปปริมาณข้อมูลของแต่ละแหล่ง
   - Graph A1: สัดส่วนผลการตรวจสอบข่าว AFNC (Donut Chart)
   - Graph A2: แนวโน้มจำนวนคดีอาชญากรรมออนไลน์รายสัปดาห์ (Line Chart)
   - Graph A3: จำนวนเหตุการณ์ AI จำแนกตามกลุ่มความเสี่ยง (Horizontal Bar Chart)
   - Graph A4: แนวโน้มคะแนนเสรีภาพอินเทอร์เน็ตของไทย (Line Chart)
3. **Section B: ข่าวปลอมและข้อมูลบิดเบือน (AFNC):**
   - ตัวกรองปี (2019–2026)
   - Graph B1: สัดส่วน Fake / True / Distorted
   - Graph B2: หมวดหมู่ประเด็นที่ถูกตรวจสอบบ่อยที่สุด (Top 10 / ทั้งหมด)
   - Graph B3: แนวโน้มรายการที่เผยแพร่ตามปี (ทุกรายการ vs เฉพาะ Verdict)
   - Graph B4: สัดส่วนผลตรวจสอบในแต่ละปี (100% Stacked Bar)
   - Graph B5: หน่วยงานที่ร่วมตรวจสอบข้อเท็จจริง (Top 10)
   - Graph B6: หมวดหมู่ของรายการที่เป็นข่าวปลอมและบิดเบือน
4. **Section C: อาชญากรรมออนไลน์ (ACSC):**
   - Graph C1: จำนวนคดีแจ้งความรายสัปดาห์ (พร้อมมาร์กเกอร์ Anomaly)
   - Graph C2: มูลค่าความเสียหายรายสัปดาห์ (หน่วยล้านบาท)
   - Graph C3: ประเภทกลโกงที่พบมากที่สุด (ความถี่อันดับ 1)
   - Graph C4: ประเภทกลโกงที่เสียหายสูงสุด
   - Graph C5: มูลค่าความเสียหายเฉลี่ยต่อคดี
   - Graph C6: Data Table แสดงข้อมูลทั้ง 48 สัปดาห์
5. **Section D: ความเสี่ยงจาก AI (AI Incident Database):**
   - หมายเหตุกำกับบริบทระดับโลก (Global Context)
   - Graph D1: กลุ่มความเสี่ยงหลัก (Risk Domain)
   - Graph D2: แนวโน้มการบันทึกเหตุการณ์ AI ตามปี (2010–2026)
   - Graph D3: ความเสี่ยงย่อยที่พบบ่อย (Top 10 Risk Subdomain)
   - Graph D4: สถิติเหตุการณ์ที่พบคำว่า 'deepfake' (KPI + Bar Chart)
   - Graph D5: ลักษณะเจตนา (Intent: Intentional vs Unintentional)
   - Graph D6: ตารางตัวอย่างเหตุการณ์ AI
6. **Section E: เสรีภาพอินเทอร์เน็ต (Freedom on the Net):**
   - KPI Cards คะแนนไทยปีล่าสุด (39/100, Access 17/25, Content 14/35, Rights 8/40)
   - Graph E1: แนวโน้มคะแนนไทย 2010–2024 พร้อมแถบสถานะ Not Free
   - Graph E2: เปรียบเทียบคะแนนระหว่างประเทศในปีที่เลือก (พร้อมช่องค้นหา)
   - Graph E3: องค์ประกอบคะแนนของไทยเทียบกับคะแนนเต็ม
   - Graph E4: การกระจายตัวของสถานะ Free, Partly Free, Not Free
   - Graph E5: Heatmap คะแนน 72 ประเทศ × 11 ปีข้อมูล
   - Graph E6: เปรียบเทียบองค์ประกอบคะแนนแบบ Normalized % กับกลุ่มประเทศอาเซียน
7. **Key Findings & Data Limitations:**
   - สรุปข้อค้นพบสำคัญ 4 ด้านด้วยภาษาเชิงพรรณนา
   - ชี้แจงที่มาและข้อจำกัดของข้อมูลทั้ง 4 แหล่งอย่างละเอียด

## 5. ข้อควรระวังในการตีความข้อมูล (Analytical Safeguards)

> ⚠️ **ข้อมูลทั้ง 4 ชุดนี้มีหน่วยวิเคราะห์และวิธีการจัดเก็บที่แตกต่างกัน ไม่ควรรวมเป็นตารางเดียวและห้ามสรุปความสัมพันธ์เชิงสาเหตุ (Causal Inference) ระหว่างกัน**

1. **ไม่สรุปความสัมพันธ์เชิงเหตุและผล:** ห้ามกล่าวอ้างว่าคะแนนเสรีภาพอินเทอร์เน็ตที่ต่ำเป็นสาเหตุทำให้ข่าวปลอมหรืออาชญากรรมออนไลน์เพิ่มขึ้น
2. **ขอบเขตของข้อมูล AFNC:** เป็นเฉพาะข่าวที่หน่วยงานเลือกหยิบยกขึ้นมาตรวจสอบ ไม่ใช่จำนวนข่าวปลอมทั้งหมดที่แพร่กระจายในสังคม
3. **การจัดการ Anomaly ของ ACSC:** สัปดาห์ 16–22 ส.ค. 2026 มีตัวเลขสูงผิดปกติ (79,311 คดี / 2,775 ล้านบาท) เก็บไว้ตามที่เผยแพร่ในเอกสารต้นทาง พร้อมใส่ข้อความและสัญลักษณ์เตือนผู้อ่าน
4. **บริบทสากลของ AIID:** เป็นฐานข้อมูลระดับโลก ไม่ใช่สถิติเฉพาะประเทศไทย และการนับ Deepfake เป็นเพียงการค้นหาคำสำคัญ (Keyword Match) ในระบบที่เกี่ยวข้อง
5. **ข้อมูลปีไม่เต็ม:** ข้อมูล AFNC ปี 2026 มีถึงเดือนตุลาคม จึงไม่นำไปเปรียบเทียบกับปีเต็มโดยตรงโดยไม่ระบุหมายเหตุ
6. **การเก็บรักษาข้อมูลดิบ:** ข้อมูลไฟล์ CSV ทั้ง 4 ไฟล์ถูกเก็บรักษาไว้ในรูปแบบดั้งเดิม ไม่มีการเขียนทับหรือลบข้อมูล
